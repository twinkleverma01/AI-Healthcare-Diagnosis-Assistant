# AI Healthcare Diagnosis Assistant

## Project Overview

AI Healthcare Diagnosis Assistant is a machine-learning-based web application that predicts a possible health condition based on selected symptoms.

The project uses Python, Flask, Pandas, and Scikit-learn. A Random Forest classification model is trained using a symptom-disease dataset and integrated with a Flask web application.



- User-friendly healthcare interface
- Symptom selection using checkboxes
- Machine-learning-based disease prediction
- Random Forest classification model
- Flask backend
- Responsive web design
- Prediction result display
- Input validation for empty symptom selection
